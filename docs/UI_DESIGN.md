## 1. 设计理念

### 1.1 定位
**AI Bead Studio = 创作工具 + 社区平台**

核心设计原则：
- **创作优先** —— 减少干扰，让用户聚焦内容创作
- **操作高效** —— 高频操作用大按钮/手势，低频操作收起到菜单
- **视觉简洁** —— 灰白底 + 主题色点缀，信息层级清晰
- **沉浸式体验** —— 编辑器全屏，工具栏半透明悬浮

### 1.2 参考产品
| 产品 | 借鉴方向 |
|------|----------|
| Procreate | Canvas 全屏编辑、手势操作、工具面板设计 |
| Pixel Studio | 像素网格渲染、颜色索引系统 |
| Figma | 图层管理、属性面板、设计令牌系统 |
| 剪映 | AI 模板选择、一键生成、社区瀑布流 |

## 2. 色彩系统

### 2.1 品牌色（Primary）
- 定义为温暖活泼的珊瑚粉，适配手工创作调性
- 主色 `#FF6B6B`，浅色 `#FF8E8E`，深色 `#E55A5A`

### 2.2 完整色板

| Token | 浅色模式 | 深色模式 | 用途 |
|-------|----------|----------|------|
| `color_primary` | `#FF6B6B` | `#FF8E8E` | 主按钮、选中态、品牌元素 |
| `color_primary_light` | `#FF8E8E` | `#FFB3B3` | 主色浅色变体 |
| `color_primary_dark` | `#E55A5A` | `#FF6B6B` | 主色深色变体、按压态 |
| `color_secondary` | `#4ECDC4` | `#5FE0D9` | 辅助色、次按钮、标签 |
| `color_accent` | `#FFE66D` | `#FFED7A` | 强调色、高亮、角标 |
| `color_bg_primary` | `#FFF5F0` | `#1A1A2E` | 页面主背景 |
| `color_bg_card` | `#FFFFFF` | `#2D2D44` | 卡片/浮层背景 |
| `color_bg_surface` | `#F8F8F8` | `#232338` | 次级表面（输入框、面板） |
| `color_text_primary` | `#2D2D2D` | `#ECEFF1` | 主文字（标题、正文） |
| `color_text_secondary` | `#757575` | `#B0BEC5` | 辅助文字（描述、副标题） |
| `color_text_hint` | `#BDBDBD` | `#607D8B` | 提示/占位文字 |
| `color_border` | `#E0E0E0` | `#3D3D5C` | 边框/分割线（明显） |
| `color_divider` | `#F0F0F0` | `#2D2D44` | 分割线（微细） |
| `color_success` | `#4CAF50` | `#66BB6A` | 成功/完成状态 |
| `color_warning` | `#FF9800` | `#FFA726` | 警告状态 |
| `color_error` | `#F44336` | `#EF5350` | 错误/删除状态 |

### 2.3 颜色使用规则
- **文本**：必须使用 `color_text_primary/secondary/hint`，禁用纯黑纯白
- **背景**：页面 `color_bg_primary`，卡片 `color_bg_card`，嵌套区 `color_bg_surface`
- **交互反馈**：主操作用 primary，危险操作用 error，次要用 secondary
- **深浅切换**：所有颜色通过 `$r('app.color.xxx')` 引用，框架自动切换

## 3. 布局规范

### 3.1 页面层级
```
┌──────────────────────────────┐
│      Status Bar (系统)       │  ← 沉浸式/透明
├──────────────────────────────┤
│      Navigation Bar          │  ← 可选：标题 + 返回/操作按钮
├──────────────────────────────┤
│                              │
│      Content Area            │  ← 主体内容（列表/网格/Canvas）
│      (layoutWeight: 1)       │
│                              │
├──────────────────────────────┤
│      Bottom Toolbar          │  ← 编辑器专用：工具按钮行
├──────────────────────────────┤
│      Tab Bar                 │  ← 全局底部导航（仅 MainPage）
└──────────────────────────────┘
```

### 3.2 卡片式布局
- 操作入口使用卡片承载
- 卡片样式：圆角 12vp、阴影 offset(0,2) radius(8) #18000000、背景 `color_bg_card`
- 卡片内边距 16vp
- 卡片间距 12-16vp

### 3.3 间距系统（8vp 基准）
| 级别 | 值 | 用途 |
|------|-----|------|
| xs | 4vp | 图标与文字间距 |
| sm | 8vp | 组件内部间距 |
| md | 12vp | 组件间间距 |
| lg | 16vp | 页面边距、卡片内边距 |
| xl | 20vp | 大区块间距 |
| 2xl | 24vp | 章节间距 |
| 3xl | 32vp | 功能区之间 |

### 3.4 内容分区
- 不同功能区域之间用 `color_divider` 0.5vp 分割线 或 16-24vp 留白
- 同组内容紧凑排列（8-12vp 间距）
- 页面顶部标题区域固定，底部操作区固定，中间内容可滚动

## 4. 组件规范

### 4.1 Card（入口卡片）
```
┌─────────────────────────────────┐
│  🎨  功能标题                    │
│      功能描述文字，最多两行       │  ← 内边距 16vp
│      [标签]                     │     圆角 12vp
└─────────────────────────────────┘     阴影 offset(0,2) radius(8)
```
- 用途：创作入口、项目列表、作品卡片
- 点击态：轻微缩放（scale 1.0 → 0.97）

### 4.2 Button（按钮）
| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 填充 primary 色，白字，圆角 8vp | 核心操作（生成、保存） |
| 次按钮 | 描边 primary 色，primary 字，圆角 8vp | 次要操作（取消） |
| 文字按钮 | 无背景，primary 字 | 轻量操作（查看更多） |
| 危险按钮 | 填充 error 色，白字 | 删除/重置 |
| 按钮尺寸 | 高度 44vp，最小宽度 88vp | 符合手指触控区域 |

### 4.3 Tab（标签导航）
- 底部 Tab：图标 24vp + 文字 10fp，高度 56vp
- 顶部分类 Tab：纯文字 14fp，选中态 primary 色下划线 2vp
- 切换动画 200ms

### 4.4 Toolbar（工具栏）
- 编辑器底部固定，高度 48vp
- 半透明背景（`color_bg_card` 90% 透明度）
- 工具按钮 44vp 正方形触控区，图标 24vp
- 选中工具 primary 色高亮

### 4.5 Bottom Sheet（底部面板）
- 圆角 20vp（仅顶部）
- 最大高度屏幕 60%
- 拖拽手柄 32vp×4vp，圆角 2vp，颜色 `color_text_hint`
- 背景 `color_bg_card`

### 4.6 Dialog（对话框）
- 居中弹出，宽度屏幕 80%（最大 320vp）
- 圆角 16vp
- 标题 18fp Bold，正文 14fp
- 按钮横向排列，主按钮在右

### 4.7 Empty State（空状态）
- 居中布局：图标 64vp + 提示文字 16fp + 引导按钮
- 图标使用 `color_text_hint` 色，低饱和度

### 4.8 Loading State（加载态）
- 居中旋转指示器（LoadingProgress） + 文字
- 或骨架屏（浅灰条闪烁动画）用于列表加载

## 6. 动画规范

### 6.1 页面切换
| 动画 | 时长 | 曲线 | 场景 |
|------|------|------|------|
| Push 进入 | 250ms | EaseOut | 从右滑入 |
| Pop 返回 | 200ms | EaseIn | 向右滑出 |
| 弹窗出现 | 200ms | EaseOut | 从底部弹出 + 淡入 |
| 弹窗消失 | 150ms | EaseIn | 向下滑出 + 淡出 |

### 6.2 组件动画
| 动画 | 时长 | 曲线 |
|------|------|------|
| 卡片出现 | 300ms | EaseOut（错开 50ms/个） |
| 按钮点击 | 150ms | EaseInOut（scale 1→0.97→1） |
| Tab 切换 | 200ms | EaseOut（下划线滑动） |
| 加载指示器 | 无限 | Linear（旋转） |

### 6.3 动画规则
- 有意义的动画（反馈操作结果、引导注意力）
- 不做纯装饰动画
- 不超过 400ms（让用户感觉即时）
- 遵循系统"减弱动态效果"设置

## 7. 图标规范

### 7.1 优先级
1. **HarmonyOS SymbolGlyph**（首选，需验证 API 24 支持）
2. **自定义 SVG**（放入 `resources/base/media/`）
3. **Unicode/Emoji**（仅开发期临时占位，正式发布前必须替换）

### 7.2 风格统一
- Tab 图标：24vp，线框(未选中) / 填充(选中)
- 工具栏图标：24vp，线框风格
- 列表项图标：20vp，线框风格
- 所有图标使用统一的描边宽度和视觉比例

### 7.3 禁止事项
- 正式页面禁止使用 emoji 作为功能图标
- 禁止混用不同风格的图标集
- 禁止图标与文字颜色不一致
