## 产品定位

一款面向拼豆手工爱好者的专业 AI 创作工具。

将照片/图片通过 AI 处理转换为拼豆图纸，提供完整的编辑、管理、导出和社区分享功能。

## 核心功能

### 1. AI 图片创作
- 上传照片进行 AI 风格化（Q版、漫画风、像素风、水彩风、素描风）
- 预留文生图能力
- AI 服务采用 Provider 抽象，方便切换后端

### 2. 拼豆图纸生成（核心）
- 图片导入 → 像素化处理 → 颜色映射
- 支持 3 个品牌调色板（Hama 48色 / Perler 60色 / Artkal 50色）
- 支持多种钉板尺寸（29×29 / 58×58 / 自定义）
- 实时预览转换结果

### 3. 图纸编辑器
- 画笔 / 橡皮擦 / 填充 / 吸色器
- 撤销/重做（50步）
- 双指缩放/平移手势
- 颜色统计与材料清单
- 导出格式：PNG / SVG（预留）/ JSON / CSV

### 4. 广场社区
- 作品发布（图纸 + 成品图 + 描述）
- 瀑布流浏览
- 标签分类（动物/卡通/风景/花纹/人物/美食/节日/其他）
- 推荐机制
- 点赞 / 收藏 / 评论
- 用户主页
